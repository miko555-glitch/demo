# The 21st Measure — Chapter 01: 1986, The First Measure

A browser-playable HTML5 side-scrolling chapter built from the supplied pixel-art source sheet.

## Run
- Keep the folder structure intact.
- Open `index.html` in a modern browser, or serve this folder with any static web host.
- The single-file version is provided separately as `The_21st_Measure_1986_Complete.html`.

## Controls
- A / D or Left / Right: move
- Shift: run
- E / Enter: investigate
- J: journal
- I: inventory
- Escape: pause (cinematic cards are advanced with Continue or Space)
- On touch screens, use the on-screen controls.

## Chapter coverage
- Ancient prologue: Henu alters the boundary measurement and binds the blue fragment to the altered page.
- 1986: first photograph, family farm investigation, paired-plot observation, irrigation reflection, boundary stone and notebook comparison, seven-day mark progression, repeated symbol, seventh-evening bank failure, and non-graphic chapter ending.
- The death sequence cuts before impact and does not show a body, as specified in the script.

## Source fidelity
The narrative sequence follows `The_21st_Measure_Script_SESHAT_Initials_v1.2.docx`. The source script identifies the first chapter as **1986**, not 1985. The character is Salah El-Rawi. A few dialogue labels in the script mistakenly say “SHERIF”; the game uses “SALAH” for those protagonist lines to preserve the character bible and avoid introducing an extra character.

## Save
Progress is saved locally in the browser under `the21stmeasure_1986_complete_v4`. Use the browser's site data controls to reset it before replaying from the prologue.
